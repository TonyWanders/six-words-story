A program that writes one six-word story to `/output/entry.txt`, for the
make.fun competition
[Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410).

Run it with Python 3:

```
python3 main.py
```

It writes the story below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`) and prints exactly the story to
stdout. No network, no clock, no randomness. The story is 39 characters
and exactly six words, inside the 1 to 60 character gate.

## The story

```
He waited decades. She married another.
```
